# 📸 picNest – CodeAlpha Internship

A simple and interactive **Image Gallery Web Page** developed as part of my **CodeAlpha Internship**.

## ✨ Features

* 🖼️ Responsive image gallery
* 📁 Folder-based image filtering
* 🔍 Lightbox image preview
* ⬅️➡️ Previous and Next image navigation
* 🔀 Shuffle images
* ✨ Smooth hover effects and transitions
* ⌨️ Keyboard navigation
* 📱 Mobile-friendly design
* 🎨 Clean and aesthetic user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Project Objective

The main objective of this project was to create a functional and visually appealing image gallery while improving my understanding of:

* JavaScript event handling
* DOM manipulation
* Dynamic content rendering
* Image filtering
* Lightbox implementation
* Responsive web design
